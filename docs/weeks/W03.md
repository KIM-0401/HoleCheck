# W03 · 환경 구축 · 테스트 모델 · Add-in 뼈대

## 목표
검사 로직에 손대기 전에 환경·API 접근 경로·테스트 모델을 확정한다.
**이번 주 매칭·판정 로직은 만들지 않는다.**

## A · 검사 로직
- Inventor API 단위 실측 · 100mm 파트의 점 좌표 반환값 확인
- 조립품 순회 · `Occurrences` 재귀 vs `AllLeafOccurrences` 비교 · 2단 중첩 모델에서 좌표 일치 확인
- 부품 → SurfaceBodies → Faces → SurfaceType(평면/원통) → EdgeLoops → Edge.GeometryType 접근 경로 확인
- HoleFeatures → Tapped / TapInfo.ThreadDesignation / IsClearanceHole / ClearanceInfo.FastenerSize 읽기 확인
- 산출: `docs/api-survey.md` (항목 · 접근 경로 · 반환값 · 결정)

## B · UI·검증·환경
- VS2022 · VB.NET · .NET Framework 4.8 · Class Library 프로젝트 생성 · Interop 참조
- `ApplicationAddInServer` 구현 · `.addin` 매니페스트 · GUID 일치 · `%APPDATA%\Autodesk\Inventor 2027\Addins\` 배치
- 리본 · Assembly 문서에만 · Tab → Panel → Button → OnExecute → 빈 WinForms 폼 Show()
- 테스트 모델 6종 제작 (models/) + `docs/test-models.md` 기대값 표
  1. 판 2장 · 관통홀 · 정확 정렬
  2. 판 2장 · 0.5mm 오프셋
  3. 카운터보어 ↔ 탭홀 M6
  4. 판 3장 · 관통 볼트 M8
  5. 압출컷 홀 (HoleFeature 없음)
  6. 패턴 4 + 미러 4

## 완료 기준
