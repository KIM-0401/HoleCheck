# W06 · 판정 재료 전환 · 피처 기반 (공동)

## 목표
구멍을 "원통면"이 아니라 "HoleFeature가 만든 면"으로 본다.
짝짓기 로직(평행 판정 · 점-직선 거리 · 후보 범위 2.0 mm · 정렬 공차 0.1 mm)은 W05 그대로 둔다.
두 군데를 동시에 바꾸면 결과 차이의 출처를 알 수 없기 때문이다.
