## 시작 전 합의
- 파일 분리 단위: A = CollectFromPart · MatchingEngine · ResultModel · GeometryHelpers / B = Globals · HoleCheckForm · EntryPoints · Zoom
- ApiProbe.vb 는 그대로 둔다(15주차 제거 예정). EntryPoints.vb(StandardAddInServer) 는 이미 분리돼 있어 이번 주 변경 없음. My Project 아래 파일도 건드리지 않음
- 명명: 헝가리안 접두 유지 · 축약 금지
- Option Strict On · Option Explicit On 유지
- 좌표: 프록시 Geometry 는 이미 조립품 좌표 (W04 결정). Transformation 을 곱하지 않고 cm→mm 만 한다. 계획서 v4 의 "파트→조립품 변환" 문구와 다르며 nested_top 으로 검증한다
- 폼: 매칭 미연결 기간 동안 그리드는 비우고 상태 라벨에 요약 한 줄 · 상세는 진단 txt · 색 표시 함수와 공차 입력 2개는 남기되 호출하지 않는다

## A
- 수집: 평면 face(kPlaneSurface) → 안쪽 EdgeLoop → 모든 edge 가 원(kCircleCurve) 인 루프만 채택
- 원 중심·지름 cm→mm
- 동심 묶음: 같은 리프 occurrence 안에서 중심 3D 거리 0.01 mm 이내면 한 묶음 · 묶음 중심은 첫 원 중심
- 지름은 리스트로 보관(오름차순) · W06 바깥 링 필터는 쓰지 않음
- 축 수집·축간 거리 코드 제거 · 거리는 묶음 중심 사이 3D 거리
- W06 피처 추적(FindHoleAncestor · GetParentFeatures)은 수집에서 빼고 보관 (W08 재사용)
