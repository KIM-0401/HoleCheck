## 이번 주 남은 것 · 관문 2 (5주차 완료, 태그 `w05-done`)

폼 실행 → 원통면 축 기반 1차 매칭 → 4열 그리드 → 행 더블클릭 시 해당 위치로 카메라 이동

### A (김영준)

- [ ] `AxisMatching.vb`: 원통면 축 수집(조립품 좌표 cm를 mm로 변환) → 축간 최단거리·각도 → 일치 / 축거리 초과 / 각도 초과 / 짝 없음
- [ ] 평행한 두 축은 일반 skew line 공식이 0으로 나누므로 점-직선 수직거리로 분기
- [ ] 압출컷 구멍 케이스 모델 제작 (이월)

### B (최승준)

- [ ] `MatchResultRow.vb`: 번호 · 오류 종류 · 값1 축간 거리 mm · 값2 각도 차 도 · 이동 지점 mm · 부품명
- [ ] `HoleCheckForm.vb`: 축간 공차(mm, 기본 0.1) · 각도 공차(도, 기본 0.5) · 실행 버튼 · 4열 그리드 · 요약 라벨
- [ ] 더블클릭 → Camera 기반 이동(Camera.Fit)

### 검증 기준

- [ ] M2(파트-12:2 + 파트-3:2) 축거리 0.707mm가 공차 0.1mm에서 "축거리 초과"
- [ ] M4(파트-1:2 + 파트-2:3)는 축이 같아 0으로 "일치"되는지 확인 (한계 기록용)
