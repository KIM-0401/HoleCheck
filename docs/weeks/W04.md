# W04 · Add-in 골격 + Inventor API 조사

## 이번 주 목표

Inventor에서 **버튼을 누르면 창이 뜨는 껍데기**를 만든다.
그리고 조립품에서 부품·구멍 정보를 **읽어올 수 있는지** 확인한다.

🔴 **이번 주에 판정 로직은 만들지 않는다.** 통로를 뚫는 주차다.

## 담당 분배 (2인)

| | 담당 |
|---|---|
| **A** | Inventor API 조사 · 구멍 정보를 어떤 속성으로 읽는지 정리 |
| **B** | Add-in 프로젝트 골격 · 리본 버튼 · 빈 폼 · 배포 스크립트 검증 |

## 할 일

### B · Add-in 골격

- [ ] `src\` 에 VB.NET 클래스 라이브러리 프로젝트 생성 (.NET Framework 4.8)
  - ⚠️ "솔루션 및 프로젝트를 같은 디렉터리에 배치" 체크
- [ ] Inventor Interop 참조 추가 · `Embed Interop Types` False · `Copy Local` False
- [ ] 컴파일 옵션 · **제한 옵션(Option Strict) = On**
- [ ] `ApplicationAddInServer` 인터페이스 구현 클래스 작성
  - `Activate` / `Deactivate` / `ExecuteCommand` / `Automation`
  - `<GuidAttribute>` · `<ComVisible(True)>` 부여
- [ ] 리본 탭·패널·버튼 생성
  - 계층 · `Ribbons.Item("Assembly")` → `RibbonTabs` → `RibbonPanels.Add` → `CommandControls.AddButton`
  - ⚠️ 조립품 환경("Assembly")에 만든다. 부품("Part")이 아니다
- [ ] 버튼 클릭 시 빈 WinForms 폼이 뜨게 연결
- [ ] `.addin` 매니페스트 작성 · `%APPDATA%\Autodesk\Inventor 2027\Addins\<폴더>\` 배포
- [ ] `scripts\deploy.ps1` 로 배포되는지 확인

### A · API 조사

- [ ] 조립품에서 부품 목록을 어떻게 얻는가 → `AllLeafOccurrences` 조사
  - ⚠️ 리프 프록시는 **누적 변환(transform)을 이미 포함**한다. 부모 변환을 또 곱하지 않도록 확인
- [ ] 부품에서 구멍 피처를 어떻게 얻는가 → `Definition.Features.HoleFeatures`
- [ ] 구멍 하나에서 읽을 수 있는 정보 정리
  - 중심 위치 · 축 방향 · 직경 · 깊이
  - `Tapped` · `TapInfo.ThreadDesignation`
  - `IsClearanceHole` · `ClearanceInfo.FastenerSize`
- [ ] 🔴 **단위 확인** · Inventor 내부 단위는 길이 **cm** · 각도 **radian**.
  mm로 보려면 환산이 필요하다. 이걸 놓치면 5주차 판정이 10배 틀어진다
- [ ] iLogic 룰로 간단히 집계해서 숫자가 나오는지 확인 (Add-in 없이도 가능)

```vb
Option Explicit On

Sub Main()
    Dim total As Integer = 0
    Dim occ As ComponentOccurrence
    For Each occ In ThisApplication.ActiveDocument.ComponentDefinition _
                        .Occurrences.AllLeafOccurrences
        Try
            total = total + occ.Definition.Features.HoleFeatures.Count
        Catch
            ' 판금·표면체 등 HoleFeatures가 없는 정의는 건너뛴다
        End Try
    Next
    MessageBox.Show("HoleFeature 총합: " & total, "집계")
End Sub
```

## 기록할 결정

- 리본 탭 · **신설 vs 기존 탭 사용** → 어느 쪽을, 왜
- 폼 프레임워크 · **WinForms vs WPF** → 어느 쪽을, 왜

⚠️ 위 4개는 되돌리기 난이도 🟠 다. **정하기 전에 팀에서 합의하고 기록할 것.**

## 막히면

| 증상 | 확인 |
|---|---|
| 추가 기능 목록에 안 뜬다 | 매니페스트 위치 · DLL이 매니페스트와 같은 폴더인가 |
| 목록엔 뜨는데 버튼이 없다 | `Activate`를 `Try/Catch`로 감싸 예외 메시지 확인 |
| 빌드가 `.exe`를 낸다 | 프로젝트 타입이 틀림 (클래스 라이브러리여야 함) |
| `dotnet build` 실패 | COM 참조는 VS GUI에서만 빌드된다 |
| 구멍 수가 0으로 나온다 | 부품(.ipt)을 열었는지 확인 · 조립품(.iam)이어야 한다 |
