# W04 · Add-in 골격 + Inventor API 실측

## 이번 주 목표

Inventor **Assembly 리본에서 버튼을 누르면 창이 뜨는 껍데기**를 만든다.
그리고 임시 진단 버튼으로 조립품의 부품·면·구멍 정보를 **실측해 개수 대조표**를 만든다.

🔴 **이번 주에는 판정·매칭·필터링 로직을 만들지 않는다.** 통로를 뚫는 주차다.

## 환경

- Autodesk Inventor 2027
- Addins 경로 · `%APPDATA%\Autodesk\Inventor 2027\Addins\`

## 담당 분배 (2인)

| | 담당 |
|---|---|
| **A** | 임시 진단 버튼 "API Probe" · 실측 5항목 · 모델별 개수 대조표 |
| **B** | 단일 Add-in 프로젝트 골격 · 매니페스트 · Assembly 리본 버튼 · 빈 폼 |

## 할 일

### B · Add-in 골격

- [ ] `src\HoleCheckAddIn` 에 **단일** VB.NET 클래스 라이브러리 프로젝트 (.NET Framework 4.8)
  - **VS에서 사람이 직접 생성**한다 (CC가 프로젝트 파일을 만들지 않음)
  - ⚠️ "솔루션 및 프로젝트를 같은 디렉터리에 배치" 체크
- [ ] Inventor Interop 참조 추가 · `Embed Interop Types` False · `Copy Local` False
- [ ] 컴파일 옵션 · **제한 옵션(Option Strict) = On**
- [ ] `ApplicationAddInServer` 인터페이스 구현 클래스 작성
  - `Activate` / `Deactivate` / `ExecuteCommand` / `Automation`
  - `<GuidAttribute>` · `<ComVisible(True)>` 부여
- [ ] `.addin` 매니페스트 작성 · `%APPDATA%\Autodesk\Inventor 2027\Addins\<폴더>\` 배포 → **로드 확인**
- [ ] 리본 · **Assembly 리본에만** 생성
  - Tab **"HoleCheck"** / Panel **"검사"** / 버튼 **"Hole Check"**
  - 계층 · `Ribbons.Item("Assembly")` → `RibbonTabs` → `RibbonPanels.Add` → `CommandControls.AddButton`
  - ⚠️ 조립품 환경("Assembly")에 만든다. 부품("Part")이 아니다
- [ ] 버튼 클릭 시 빈 폼 `Show()`
- [ ] (보류) `scripts\deploy.ps1` 로 배포되는지 확인 — 합의 범위에 없음

### A · API 실측 (임시 진단 버튼)

- [ ] B와 **같은 Panel("검사")** 에 임시 진단 버튼 **"API Probe"** · 코드는 `ApiProbe.vb`
- [ ] 결과는 **텍스트 파일**로 출력
- [ ] 실측 5항목
  1. **단위** · `RangeBox` 원값을 그대로 기록해 내부 단위(cm) 확인
     - 참고 · Inventor 내부 단위는 길이 **cm** · 각도 **radian**. 이걸 놓치면 5주차 판정이 10배 틀어진다
  2. **Occurrences 재귀 vs `AllLeafOccurrences`** 좌표 비교
     - ⚠️ 리프 프록시는 **누적 변환(transform)을 이미 포함**한다. 부모 변환을 또 곱하지 않도록 확인
  3. **부품 → 면 → EdgeLoop → Edge** 개수
  4. **HoleFeature 탭·클리어런스 속성** (`Definition.Features.HoleFeatures`)
     - `Tapped` · `TapInfo.ThreadDesignation`
     - `IsClearanceHole` · `ClearanceInfo.FastenerSize`
  5. **패턴·미러 피처 수**
- [ ] 🔴 판정·매칭·필터링 로직은 만들지 않는다 (세기·기록만)
- [ ] 산출 · **모델별 개수 대조표**

  | 모델 | HoleFeature 수 | 원통면 수 | 원형 edge 수 | 원형 안쪽 루프 수 | 기대값과 차이 이유 |
  |---|---|---|---|---|---|

- [ ] (보류) 구멍 하나의 중심 위치 · 축 방향 · 직경 · 깊이 정리 — 합의 범위에 없음
- [ ] (보류) iLogic 룰로 간단히 집계해서 숫자가 나오는지 확인 (Add-in 없이도 가능) — 합의 범위에 없음

```vb
Option Explicit On

Sub Main()
    Dim total As Integer = 0
    Dim occ As ComponentOccurrence
    For Each occ In ThisApplication.ActiveDocument.ComponentDefinition _
                        .Occurrences.AllLeafOccurrences
        Try
            total = total + occ.Definition.Features.HoleFeatures.Count
        Catch
            ' 판금·표면체 등 HoleFeatures가 없는 정의는 건너뛴다
        End Try
    Next
    MessageBox.Show("HoleFeature 총합: " & total, "집계")
End Sub
```

## 막히면

| 증상 | 확인 |
|---|---|
| 추가 기능 목록에 안 뜬다 | 매니페스트 위치 · DLL이 매니페스트와 같은 폴더인가 |
| 목록엔 뜨는데 버튼이 없다 | `Activate`를 `Try/Catch`로 감싸 예외 메시지 확인 |
| 빌드가 `.exe`를 낸다 | 프로젝트 타입이 틀림 (클래스 라이브러리여야 함) |
| `dotnet build` 실패 | COM 참조는 VS GUI에서만 빌드된다 |
| 구멍 수가 0으로 나온다 | 부품(.ipt)을 열었는지 확인 · 조립품(.iam)이어야 한다 |
